# تسميع — Tasme3

**A free, open-source Quran memorization trainer. Sadaqah jariyah — free forever, for everyone.**

تطبيق مجاني مفتوح المصدر للمساعدة على حفظ القرآن الكريم: يقرأ الحافظ غيبًا، والتطبيق يستمع ويُظهر الكلمات الصحيحة **كما هي مطبوعة في صفحات مصحف المدينة تمامًا** — الكلمات غير المقروءة تبقى مخفية حتى تُتلى صحيحة.

The user recites from memory; the app listens and reveals each word **exactly as printed on the real Madinah mushaf page** — unrecited words stay hidden until spoken correctly.

## Principles / المبادئ

- **Zero errors in Quranic text** — all text, fonts, and page layouts come exclusively from official King Fahd Complex (KFGQPC) open sources, cross-verified with committed evidence. Nothing is ever re-typed by hand or generated by AI.
- **The real printed page** — the screen shows an image of the actual mushaf print (rendered from the official per-page KFGQPC fonts), never re-flowed text.
- **Built for weak internet and old phones** — the client is a tiny static PWA; each page costs one small image (~100–200 KB) + ~5 KB of data. Speech recognition (Whisper) runs on the server, so the phone never downloads a model.
- **Free forever** — charity project (sadaqah jariyah). No ads, no fees, no monetization, ever.
- **Multilingual UI** — 12-language catalog (the Quran itself is always Arabic, untouched).

## Data sources (all free / official)

- **KFGQPC (King Fahd Glorious Quran Printing Complex)** — Uthmani Hafs text and per-page mushaf glyph fonts
- **QUL (qul.tarteel.ai)** and open quran.com datasets — page layout and word-by-word data used for cross-verification
- Reciter audio for listen-and-repeat (Sheikh al-Husary) — free per-ayah sources, documented in `docs/`
